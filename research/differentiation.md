# Differentiation

XIR is the semantic layer connecting existing standards, not replacing them (Sec 54):

```text
                SEMANTIC EXPERIENCE MODEL (XIR)
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
      Design                Agent                  Code/API
        │                     │                     │
   Figma/tokens          MCP/A2UI/AG-UI      React/HTML/OpenAPI
```

Unique bundle: product intent + capabilities + surfaces + state machines + flows + invariants +
provenance/uncertainty + stable IDs + L0–L6 slicing + patches + semantic diff + validator, in one
authorable DSL compiling to all of the above. No single related system covers that conjunction.
Self-criticism (Sec 53) applies per feature: keep only what measurably helps agents.
