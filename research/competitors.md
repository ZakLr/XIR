# Competitors (nearest approaches)

| Approach | What it is | Why insufficient for thesis |
|---|---|---|
| Figma + Code Connect | design→code link | pixels, no flows/permissions/provenance/queries |
| A2UI / Adaptive Cards | portable UI JSON | render only, no intent/capabilities/state machine |
| MCP tool lists | agent tools | wire protocol, no product model behind tools |
| OpenAPI + JSON Schema | API contracts | data only, no surfaces/flows/UI |
| UML/Statecharts tools | modeling | heavy, drifts, no compiler targets for UI/agents |
| Screenshot+code agents | status quo baseline | huge context, ambiguous, no stable IDs/diffs |

XIR wins only if measured: fewer tokens, fewer retrievals, fewer mistakes, better behavioral fidelity
(Sec 51/56). Otherwise integrate, don't reinvent.
