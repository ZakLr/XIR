# Open problems

1. Extraction fidelity: app→model miners for React/HTML/Figma don't exist yet; hand-authored only.
2. Layout semantics ceiling: constraints (sidebar→drawer, table→list) covered; fine responsive + motion not.
3. Formal verification depth: validator catches structural issues; no temporal/logic proofs.
4. Provenance at scale: per-node source/confidence authoring cost vs inference risk.
5. Retrieval calibration: L0–L6 + query routing is heuristic; no learned context-priority yet.
6. Cross-target fidelity metrics: visual/a11y equivalence measures are crude proxies.
7. Ecosystem extensions (ecommerce/healthcare/gaming) without core fragmentation.
8. Baseline A/B rigor: blinded agent trials with token/correctness stats still to run at scale.
