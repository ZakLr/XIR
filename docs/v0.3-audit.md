# v0.3 audit — where the current architecture blocks richer semantics

Baseline before change: 14 tests pass, 20/20 benchmark tasks, round-trip STABLE.

## Findings

1. **AST doubles as semantic IR** (`src/xir/ast/nodes.py`). No node has an `id`.
   `semantic/graph.py:14` derives identity from the display name, so `archiveProject`
   → `archiveProject2` is indistinguishable from delete+add. Blocks §4, §18, §33-identity.
2. **Graph depends on parser structures** (`semantic/graph.py:5` imports `ast.nodes`).
   Blocks §3 (IR as source of truth) and §13 (typed semantic relationships).
3. **Phantom nodes**: `semantic/graph.py:33` writes edges to `perm.{r}` for permission
   strings with no declaration, so the graph accumulates untyped dangling nodes.
4. **Identity inferred from string co-occurrence**: `requires`, `effects`, `presents`,
   component membership, flow steps are all strings. `effects` is literally
   `"project.status = archived"` — precisely the inference §6 forbids.
5. **State is a bag of names** (`Surface.states: list[str]`). No initial state, no
   transitions, no event. Blocks §10, §11, §33-state.
6. **Flow steps are flattened strings** (`Flow.steps: list[str]` from `A -> B`). Source,
   action, destination, condition, branch all lost. Blocks §12.
7. **Components are names** (`Surface.components: list[str]`). No presents/invokes/
   states/containment. Blocks §8.
8. **Actors are names** (`Experience.actors: list[str]`). No permission grants. Blocks §7.
9. **Query is substring routing** (`query/engine.py`, `if "capability" in q`). Blocks §15, §16.
10. **Patches mutate AST in place** with no rollback and no reference updates, so a
    rename leaves dangling references. Blocks §17, §33-patches.
11. **Parser silently degrades**: `parser/parse.py` catches every strict error and returns
    a tolerant parse, so malformed XIR becomes a plausible wrong model. Violates §21.
12. **Compilers are string stubs** (`compiler/emit.py`). Blocks §23, §24, §33-compiler.
13. **Benchmarks are string-presence proxies**. §25/§27 forbid presenting them as proof.

## Plan (per §34 order)

Phase 1 stable IDs + IR separation + Component/Permission/Event/Interaction/Goal.
Phase 2 state machines + rich flows + typed graph.
Phase 3 inspect/trace/structural queries + rename-aware diff + atomic patches.
Phase 4 rich validation + evidence + round-trip.
Phase 5 real React target + semantic Playwright.
Phase 6 honest benchmark (MEASURED/SIMULATED/INFERRED labels).

Constraint honoured: no Tree-sitter (§22), no vector/embedding/DB work (§32),
no new compiler targets beyond the one real React target (§23).
